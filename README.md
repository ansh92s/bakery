## 🧁 Project Overview

**Sweet Haven Bakery** is a charming, multi-page website that showcases a fictional bakery’s delicious creations — from freshly baked pastries to artisan coffees.  

The project focuses on:
- ✨ Clean and semantic **HTML5 structure**
- 🎨 Aesthetic and responsive **CSS3 design**
- 📱 **Mobile-friendly navigation** for seamless browsing

---

## 🌟 Key Features

- 🍩 **Multi-Page Navigation** — Dedicated pages for *Home*, *Menu*, *Pastries*, and *Contact*  
- ☕ **Warm Aesthetic** — A soft, cozy color palette (`#ffb3c6`, `#fff8f6`, `#5a3e2b`) and elegant typography  
- 🎂 **Menu & Pastry Showcases** — Detailed listings with descriptions and pricing  
- 💌 **Contact Page** — Includes an inquiry form, location map, and business hours  
- 📱 **Responsive Design** — Optimized for all screen sizes with a mobile hamburger menu  
- ⚙️ **Lightweight JavaScript** — For smooth navigation and toggle animations
